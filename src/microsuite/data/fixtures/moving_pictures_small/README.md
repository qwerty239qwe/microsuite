# Moving Pictures Small Fixture

This directory contains a tiny deterministic fixture for `microsuite` tests and
examples. It is not owned by this project and is not the full Moving Pictures
dataset.

The fixture uses Moving Pictures-style sample identifiers and metadata fields,
with reduced table contents suitable for unit tests.

Scientific source to cite:

Caporaso, J. G., Lauber, C. L., Costello, E. K., Berg-Lyons, D., Gonzalez, A.,
Stombaugh, J., Knights, D., Gajer, P., Ravel, J., Fierer, N., Gordon, J. I.,
and Knight, R. Moving pictures of the human microbiome. Genome Biology 12, R50
(2011). https://doi.org/10.1186/gb-2011-12-5-r50

The full tutorial artifacts fetched by `microsuite data fetch moving-pictures
--full` are distributed through the QIIME 2 Moving Pictures tutorial.
